Pushlog Privacy Policy

Effective date: October 7, 2026

Pushlog is a browser extension designed to help developers inspect and debug analytics implementations.

Information collection

Pushlog does not collect, store, transmit, sell, or share personal information with the extension developer or any third party.

Data processing

Pushlog processes analytics events locally within your browser so it can show them for debugging. It reads:

  • Adobe Client Data Layer calls (adobeDataLayer.push)
  • Adobe Experience Platform Web SDK calls (alloy("sendEvent"))
  • Google Tag Manager calls (dataLayer.push and gtag)

It also keeps the URL of the tab you are inspecting so the timeline stays attached to that page. The extension runs on HTTP and HTTPS pages in order to see those calls. It does not read form fields, passwords, or cookies, and it does not send page contents anywhere.

Data storage

Captured event data, including the tab URL and event payloads, is stored locally on your device with Chrome extension storage. Closing a tab clears that tab’s timeline. This data is not transmitted to external servers operated by Pushlog.

Third-party services

Pushlog does not use third-party analytics, advertising networks, or remote code execution services.

Data sharing

Pushlog does not sell, transfer, or disclose user data to third parties.

Changes to this policy

This policy may be updated periodically. Any updates will be reflected on this page.
